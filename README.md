# Learn SecByte Cron, SMB, LinPEAS, MD5 & LFI Root CTF Labs

## Introduction

This repository collects hands-on cybersecurity and CTF labs focused on Linux enumeration, cron-job security, SMB shares, writable resources, pspy64 process monitoring, LinPEAS enumeration, MD5-related challenges, SSH authentication testing, Hydra, Local File Inclusion (LFI), and root-shell workflows.

The collection is designed for cybersecurity students, CTF players, penetration testers, SOC analysts, and security learners who want practical experience with Linux privilege escalation and vulnerability discovery in authorized environments.

## Learning Path

A practical progression through this collection is:

1. **Start with Linux enumeration** — understand users, processes, permissions, services, and system configuration.
2. **Explore cron security** — identify scheduled tasks and investigate their execution context.
3. **Study pspy64** — observe processes and scheduled activity during enumeration.
4. **Practice SMB enumeration** — inspect shares and identify potentially writable resources.
5. **Use LinPEAS concepts** — organize Linux privilege-escalation enumeration.
6. **Study authentication challenges** — work with MD5-related clues, SSH, and Hydra in the lab environment.
7. **Learn LFI concepts** — understand how local file inclusion can expose system information.
8. **Connect findings to privilege escalation** — analyze how individual weaknesses can form a complete attack path.

## How to Use the Labs

1. Select a lab from the collection.
2. Review the lab objective and authorized target.
3. Begin with reconnaissance and enumeration.
4. Identify users, services, processes, permissions, shares, and scheduled tasks.
5. Document important findings.
6. Investigate vulnerabilities only within the permitted lab environment.
7. Analyze why each weakness exists and how it could be mitigated.
8. Record the techniques and lessons learned for future CTF and security assessments.
